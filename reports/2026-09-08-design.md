# 전체 디자인 변경 결과

작성: 2026-09-08 (KST)

## 상태와 목표

사용자의 전체 디자인 현대화 요청에 따라 구현·검증을 완료했다. 2026-09-08 사용자가 ADRGAP 앞 아이콘 제거와 나머지 디자인의 Git 반영·배포를 승인했으며 **운영 배포와 실제 사이트 확인까지 완료했다.** 코드 커밋은 `66ee84fe52d9985369146c8c920eff2363ccf539`이다. 배포 전 기준 커밋은 `f817ef6942dcc691969bd712fa29e0e1fb4d8f27`이며 당시 운영 코드는 `b9696d2`다.

기존 Yahoo 시세와 계산 정책을 유지하면서 여러 기업의 가격을 빠르게 비교할 수 있는 화면으로 정리했다. 신규 공급처·계정·DB·Supabase·Vercel·추가 자동 갱신은 도입하지 않았다.

## 변경 내용

- 화이트·쿨그레이 바탕, 네이비 글자, 블루 강조색, 얇은 구분선과 Inter/Noto Sans KR 글꼴로 정리했다.
- ADRGAP 글자형 헤더와 단순한 기업 티커 모노그램을 적용했다. 사용자 요청에 따라 홈·가이드·약관·개인정보 페이지에서 ADRGAP 앞 아이콘을 제거했다. 기업 티커 모노그램은 그대로이며 기업 공식 로고로 표현하지 않는다.
- 기업 티커 모노그램은 미국 ADR 전체 티커를 표시한다(SKHY, KB, SHG, PKX 등). 좁은 화면에서도 잘리지 않도록 박스 폭을 조정했다.
- 데스크톱 요약 행에서 기업, 국내 환산가(ADR 1주 기준 USD), 미국 ADR 가격(USD), ADR 괴리율을 열로 정렬했다.
- 모바일은 같은 두 USD 가격과 괴리율을 카드로 보여 주며, 상단 설명·환율 영역의 높이를 줄였다.
- 새 방문자는 모든 기업을 접힌 상태로 시작한다. 기존 브라우저에 저장된 관심·펼침 설정은 동일한 키로 그대로 복원한다.
- 펼친 상세의 국내·미국 원본 가격, 환산가, 양방향 괴리율은 유지한다. 요약은 기존 ADR 기준 괴리율 하나이며 높음·낮음을 같은 색으로 표시한다.
- 기존 오류 영역을 환율 아래로 이동했다. 오류 판정이나 새로고침 성공 판정 로직은 이번 디자인에서 변경하지 않았다.
- 가이드·이용약관·개인정보처리방침에도 같은 헤더와 공통 스타일을 적용했다. 기존 안내·법적 본문 내용은 유지했다.
- 초기·자동 캐시, 수동 `force=1`, 한국 정규장 메타값 우선 및 1분봉 fallback, 미국 시간외·시각 표시, 분석 계정 설정은 유지했다.

## 검증 결과

최종 `pnpm verify` 전체 통과:

- 단위·API 검사 35개 통과, 실패 0개.
- 아이콘 제거 후 Wrangler 배포 없는 빌드 통과: 70.22 KiB, gzip 19.66 KiB. `--dry-run`이므로 실제 배포가 아니다.
- Chromium 데스크톱 1440px·모바일 390px 검사 통과.
- 9개 기업 요약의 두 USD 가격과 괴리율 계산, 각각의 원본 기준 시각·미국 시장 라벨 확인.
- 초기 일반 API 요청 2회, 수동 강제 API 요청 1회 확인. 원본이 같으면 기준 시각을 그대로 유지.
- 오류 복구·잘못된 값·stale·부분 실패·뒤늦은 이전 응답 방어 검사 통과.
- 고정·해제·키보드 포커스·설정 복원·저장소 파손/차단 검사 통과.
- 최소 44px 조작 영역, 320px 폭 및 200% 글자 확대에서 가로 넘침 검사 통과.
- 가이드·약관·개인정보 페이지의 경로·공통 스타일·이동 링크·확대 표시 검사 통과. 확대 시 약관의 긴 이메일 주소가 넘치는 문제를 줄바꿈 스타일로 수정했다.

자동 회귀 검사는 외부 요청을 차단한 모의 시세를 사용한다. 별도로 로컬 Worker에서 실제 Yahoo 응답과 웹폰트를 로드해 데스크톱·모바일·상세·가이드 화면을 캡처하고 육안 확인했다. 모바일 검사는 Chromium 뷰포트 에뮬레이션이며 실물 휴대폰/Safari 검사는 아니다.

390×844 모바일 캡처에서는 처음부터 기업 요약 카드 2개 전체와 다음 기업 제목이 보인다. 기존의 SK하이닉스 기본 펼침을 모두 접힘으로 바꾼 영향이 포함된다. 저장된 펼침 설정이 있는 브라우저에서는 결과가 다를 수 있다.

## 다음 행동과 위험

화면 확인과 아이콘 제거·배포 승인에 따라 GitHub main 반영 및 기존 Cloudflare Builds 배포, 운영 검증을 완료했다. 추가 개발 작업 없이 기존 정기 운영 점검을 유지한다. 문제가 확인되면 현상을 보고하고 승인 후 이전 검증 버전 복원 또는 revert를 사용한다.

Git 커밋 제목 초안: `ADR 비교 화면과 안내 페이지 디자인 개편`

설명 초안: 비교 가능한 USD 가격을 요약에 정렬하고 공통 화이트·블루 스타일을 적용한다. 최초 펼침 상태를 간결하게 바꾸되 저장 설정과 시세 정책은 유지하며 반응형·확대 회귀 검사를 보완한다.

새 원본 호출 증가는 없다. Inter는 기존 Google Fonts 방식으로 추가되어 첫 방문의 폰트 다운로드가 늘 수 있으며, 로드 실패 시 시스템 글꼴로 대체한다. Yahoo 원본 지연과 시장 시간 차이, ADR 비율·기업행동·이용 조건은 기존 운영 점검 대상으로 남는다.
