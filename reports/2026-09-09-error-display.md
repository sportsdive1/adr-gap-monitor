# 시세 오류 시 요약·상세 가격 초기화

2026-09-09 (KST). 사용자 승인 범위: 오류 표시 수정과 로컬 검증. **Git 커밋·push·Cloudflare 배포는 하지 않았다.**

## 변경 내용

정상 조회 후 해당 기업의 국내/ADR 시세 또는 환율이 누락되거나 유효하지 않으면, 요약 가격은 비워지지만 상세에는 직전 가격이 남는 문제가 있었다. `assets/app.js`의 `issue()`가 요약의 두 값만 초기화한 것이 원인이다.

같은 오류 처리 경로에서 요약 두 가격과 상세 네 값(국내 시세·미국 ADR 시세·달러 환산가·원화 환산가)을 모두 `—`로 초기화한다. 기준 시각 영역·괴리율 설명은 기존 오류 문구를 유지한다. 해당 기업의 비교 전체가 불가능한 상태를 일관되게 보여 주는 최소 수정이다.

수정 파일:

- `assets/app.js`: 오류 때 요약·상세 가격을 함께 초기화.
- `index.html`: 기존 스크립트 버전 쿼리를 `20260909-errors`로 갱신. 이후 승인된 배포 시 이전 클라이언트 캐시와의 혼용을 줄임.
- `tests/browser.mjs`: 정상 → 오류 → 정상 복구 및 이전 시세 유지 회귀 검사 추가.
- 이 보고서와 `PROJECT_HANDOVER.md`, `DEVELOPMENT_CHAT_HANDOFF.md`: 로컬 완료·미배포 상태 기록.

## 유지한 정책

- 유효한 이전 값이 `stale`로 제공되면 숫자를 유지하고 기존 `이전 시세 · 확인 필요`로 표시한다.
- 요청 전체가 통신 오류로 실패했지만 직전 정상 표시가 있으면 기존 `갱신 실패 · 이전 표시`와 가격·원본 시각을 유지한다.
- 정상 시세, 계산식, Yahoo 단일 공급처, 한국 정규장/미국 시간외 정책, 캐시, 수동 `force=1`, 자동 갱신 주기를 바꾸지 않는다.
- 화면 구성·문구·스타일·관심/펼침 설정·분석 이벤트를 바꾸지 않는다. 새 API 요청·폴링·외부 공급처는 추가하지 않는다.

## 검증 결과

1. 수정 전 새 회귀 테스트 실행: 예상대로 실패. 요약 두 값은 `—`였지만 상세 네 값은 직전 숫자여서 문제를 검출했다.
2. 수정 후 `pnpm verify` 성공: 단위/API 41개 모두 통과, Wrangler 4.112.0 `--dry-run` 빌드 성공, 데스크톱 1440px·모바일 390px 브라우저 검사 통과.
3. 잘못된 국내 가격(0), 국내 시세 누락, 미국 ADR 시세 누락, 환율 누락, 잘못된 환율(0), 첫 진입 API 실패에서 요약·상세 가격 초기화를 확인했다.
4. 다음 정상 응답에서는 새 테스트 값에 맞는 9개 기업의 가격·환산가·괴리율·기준 시각·시장 라벨 복구를 확인했다. 일부 기업 오류가 정상 기업의 표시를 비우지 않는 것도 확인했다.
5. 유효한 이전 시세/환율 사용과 요청 전체 통신 실패에서 기존 가격 유지·오류 구분을 확인했다.
6. 기존 초기 API 요청 2회·수동 `/api/market?force=1` 1회, 카드 14px 간격, 관심/펼침 복원, 320px·200% 글자 확대, 안내 페이지 및 JavaScript 비활성화 검사를 통과했다.
7. 수정 파일의 `git diff --no-index --check`에서 공백 오류 없음. 비교 과정의 LF/CRLF 경고는 줄바꿈 설정 안내이며 파일을 변환하지 않았다.

테스트는 로컬 Worker와 모의 응답을 사용했다. Yahoo·운영 분석·외부 폰트 요청을 차단했으며, 실제 Yahoo 시세 최신성이나 운영 반영을 검증한 결과가 아니다.

## Git 초안·배포 조건

- 커밋 제목 초안: `시세 오류 시 상세 이전 가격 잔존 수정`
- 설명 초안: `유효하지 않은 시세·환율 응답에서는 요약과 상세 가격을 함께 초기화한다. 정상 복구·부분 실패·이전 값 유지 회귀 검사를 추가하고 클라이언트 스크립트 버전을 갱신한다.`
- 이번 검토의 Git 복제본 기준: `69de613` (`배포 및 도메인 연결 결과 기록`). 복제본에 변경 파일을 복사하거나 Git 이력을 변경하지 않았다. 기존 추적되지 않은 인수인계 두 파일도 그대로 보존했다.
- 운영 적용에는 별도 Git/배포 승인이 필요하다. 승인 후 원격 main 최신 상태 재확인 → 파일별 대조·검증 → GitHub main → Cloudflare Workers Build → 실제 운영 반영 확인 순서로 진행한다.
- 배포 후 PC·모바일 정상 시세·기준 시각·수동 force를 확인하고, 브라우저에서 API를 모의 오류로 대체해 상세 잔존·복구를 확인한다. 운영 데이터를 변경하거나 Yahoo 오류를 인위적으로 일으키지 않는다.

## 남은 위험·한계

Yahoo 자체 지연·조회 실패를 해결하는 변경은 아니다. 비교에 필요한 값이 없는 기업은 전체 가격 표시를 비우며, 이전 값 사용 정책은 기존 구분을 따른다. 금융 계산·매매 유도 기능은 추가하지 않았고, 파비콘·공유 이미지·검색 콘텐츠 개선도 이번 범위에 포함하지 않았다.
