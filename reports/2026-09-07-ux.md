# 기업별 비교·모바일·브라우저 설정 개선 결과

작성: 2026-09-07 KST
상태: **로컬 구현·검증 완료. Git 커밋·push·Cloudflare 배포는 하지 않음.**

## 승인 범위와 결과

사용자가 추천안의 “전체 기업 요약 → 모바일 가독성 → 관심 기업·펼침 상태 기억”을 승인했다. 이전 안정성 개선을 보존한 상태에서 구현했다.

- 9개 기업 모두 펼치지 않고 ADR 기준 괴리율을 비교할 수 있다.
- 요약에서 국내/ADR의 원본 기준 시각과 정규장·시간외 라벨을 각각 확인할 수 있다.
- 실제 국내/ADR 시세와 환산가의 라벨을 분리했다. 달러 환산은 ADR 1주 기준, 원화 환산은 국내 주식 1주 기준이다.
- 별 버튼으로 관심 기업을 위에 고정하고, 기업별 펼침 여부를 같은 브라우저에서 기억한다.
- 기존 분홍 계열 디자인을 유지하며 정보 간격·모바일 줄바꿈을 정리했다. 일반 라벨 14px, 보조 정보 12px 이상, 버튼 최소 높이 44px, 키보드 포커스 표시를 적용했다.
- 단일 HTML 카드 템플릿을 복제하고 이벤트를 공통 처리한다. 새로고침 때 기존 카드 전체를 다시 만들지 않는다.

## 비교와 오류 표현

요약 계산은 모든 기업에서 다음과 같다.

```text
국내의 ADR 1주 기준 달러 환산가 = 국내 시세 × ADR당 보통주 수 ÷ USD/KRW
ADR 기준 괴리율 = (ADR 시세 ÷ 국내의 ADR 1주 기준 달러 환산가 - 1) × 100
```

표시는 높음/낮음이며 두 방향 모두 같은 색을 쓴다. 괴리율 순위, 저평가·고평가 판정, 매매 신호는 추가하지 않았다. 반올림한 0.00%는 “거의 같음”으로 표시한다.

잘못된 값은 “비교 불가”, 이전 값 사용은 “이전 시세 · 확인 필요”, 요청 자체 실패는 “갱신 실패 · 이전 표시”로 구분한다. 정상적으로 같은 원본 시각이 돌아오는 경우는 오류가 아니다. 기존 상세의 가격 기준과 미국 시세 라벨 정책은 유지한다.

## 이 브라우저의 설정

- 키: `adrgap.preferences.v1`.
- 저장 항목: 버전, 관심 기업 ID 목록, 기업별 펼침 여부만. 시세·환율·계정은 저장하지 않는다.
- 처음에는 SK하이닉스만 펼친다. 이후 같은 브라우저·출처(origin)의 설정을 복원한다.
- 관심 그룹과 나머지 그룹 안에서는 기존 기업 설정 순서를 유지한다.
- 다른 브라우저·기기·운영 도메인과 localhost 사이에는 동기화하지 않는다.
- JSON 손상, 알 수 없는 기업, 저장소 접근·쓰기 차단에 대응한다. 저장 불가 시 현재 방문 중 화면 조작은 계속 가능하다.
- 브라우저에서 사이트 데이터를 삭제하면 초기화된다.
- 관심 이벤트를 새로 수집하지 않는다. 상태 복원만으로 기존 펼침 이벤트를 발생시키지 않는다.

## 배포 및 다음 행동

1. 사용자가 로컬 화면과 결과를 확인한다.
2. 명시적인 Git 반영·Cloudflare 배포 승인을 받은 뒤 진행한다.
3. 이전 안정성 개선과 이번 UX 개선의 파일을 함께 확인한다. 화면 파일만 운영에 올리고 새로운 `assets/`·`src/` 경로를 빠뜨리면 안 된다.
4. GitHub main → Cloudflare Build 성공 → 실제 adrgap.com 데스크톱·모바일 순서로 확인한다.
5. 운영에서 수동 `force=1`, 국내/ADR 시각·환율, 관심 복원, 웹폰트, 가이드·약관·개인정보 링크를 확인한다.

Git 커밋 초안:
- 제목: `기업별 ADR 비교 요약과 브라우저 관심 설정 개선`
- 설명: `9개 기업의 ADR 기준 괴리율·시각 요약, 모바일 가독성, 관심·펼침 상태 기억과 회귀 검사를 추가. 공급처·시세 정책·자동 갱신 횟수 유지.`

Supabase·Vercel·회원가입·DB·새 공급처·추가 폴링은 필요하지 않아 도입하지 않았다. 브라우저 설정 기억은 계정 기반 동기화 기능이 아니다.

## 작업 지침 적용

Sites의 기존 사이트 보존 지침에 따라 기존 Cloudflare 구조·패키지·브랜드를 유지했다. 읽기 크기·터치/포커스·반응형 기준을 적용했으며, 브라우저 저장은 승인된 기기 로컬 UI 설정에만 한정했다. 새 호스팅 프로젝트나 배포는 만들지 않았다.
