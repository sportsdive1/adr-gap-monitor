# 모바일 기업 카드 간격 개선

작성: 2026-09-08 KST
상태: GitHub main 및 Cloudflare 운영 반영 완료.

## 변경

모바일에서 기업 정보의 시작과 끝을 구분하기 쉽도록, 화면 폭 760px 이하에서 기업별 카드를 분리했다.

- 카드 사이 14px 여백과 배경색 노출.
- 각 카드에 1px 테두리와 기존 14px 둥근 모서리 적용. 마지막 카드에도 하단 테두리 유지.
- 기존 내부 여백·글자 크기, 상세 펼침 배경, 관심 기업 표시 유지.
- 데스크톱은 기존 연속 표 형태 유지.

코드 변경 파일은 `assets/styles.css` 하나다. 시세 처리·계산·API 호출·화면 문구 변경은 없다.

## 검증

`pnpm verify` 통과: 35개 단위/API 검사, 배포 없는 Wrangler 빌드, 기존 브라우저 회귀 검사.

- Chromium 1440×1000 데스크톱, 390×844 모바일 검사 통과.
- 320px 및 글자 200% 확대에서 가로 넘침 없음.
- 상세 펼침·접기, 관심 기업 정렬·설정 복원, 수동 force 요청 검사 통과.
- 데스크톱·모바일 캡처를 직접 확인했다. 모바일은 기기 에뮬레이션이며 캡처의 시세는 테스트용 모의 데이터다.
